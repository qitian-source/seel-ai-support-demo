背景与目标

背景

Review Agent 已上线，在客服对话解决问题后自动邀请满意顾客去 Trustpilot 留评，并把评价归因回具体会话。但商家侧的后台还停留在早期版本，让商家看不清效果、也不好上手：配置项和数据挤在同一页；效果只有一个累计总数，看不出一段时间内的趋势；看不到邀请具体发给了谁、结果如何；顾客留下的好评内容在后台完全不可见；每日上限设为「无限」时还会显示成 "Capped at 0/day" 这类费解文案。结果是商家常常觉得"这功能没效果"，却无从判断，也不敢调。

目标

把商家后台做成一个能自证价值、能自助运营的地方——让商家运营不需要找我们，就能回答"效果好不好、发给了谁、好评说了啥、怎么配"。

成功衡量

  • 商家能自助完成配置并读懂数据，因"看不到效果 / 不会配"产生的支持工单下降。
  • 看得到好评内容后，商家把归因好评用于营销 / 回应的比例上升。
  • 配置防错到位，"开着但 Trustpilot 没连 / 配错导致 0 归因"的商家占比趋近于 0。

不在本版范围

后端归因 / 触发 / 发送逻辑（已上线运行，其口径与接口见上游文档 PRD-review-agent.md，本文档不展开）· 灰度控制（已有）· 今日用量指示（明确不做）· 后续版本再议项（漏斗诊断建议、邀请时机 A/B、多平台归因、归因申诉等）。

功能需求

后台分 数据表现 与 设置 两块：数据与配置分开呈现；看数据与改配置按权限区分可见，无权限时给出明确提示而非整页空白。总开关只出现一处（在设置里）；并在 Support Agent 的 widget 设置中提供"前往 Review Agent"的入口，方便被发现。

3.1 效果度量（数据表现）

用户故事：作为商家运营，我想按时间段看清邀请到好评的转化，以便判断价值、决定投放力度。

需求：

  • 可选时间范围：昨天 / 近 7 天 / 近 30 天 / 近 90 天 / 自定义起止，页面数据随之联动。
  • 一组关键指标，均带与上一周期的环比（涨绿跌红）：邀请展示、邀请点击、点击率、评价数、评价率、五星评价——覆盖"发出去 → 多少人点 → 多少人真留评 → 多少是五星"整条链路。
  • 指标口径不产生误解：每个指标都能悬浮看到通俗定义（例如"邀请展示"= 邀请卡在顾客对话里出现的次数，不是发邮件）。原易误解的 "Invites Sent" 改为"邀请展示"。
  • 关闭功能不影响看历史：关闭后停止发新邀请，但历史数据照常可查，页面明确提示"已暂停发送"。

验收：切换时间范围时全部指标同步更新；每个指标可悬浮看到定义；关闭功能后历史数据仍在。

3.2 会话与评价

用户故事：作为商家运营，我想知道邀请发给了谁、结果如何、好评写了什么，以便跟进和对外展示。

需求：

  • 逐条会话 + 结果状态：每条被邀请的会话显示状态——已邀请 / 已点击 / 已评价 / 已过期，且能悬浮看懂含义（"已邀请"= 展示了但顾客还没点，会一直停留；"已过期"= 点了但在归因时限内没匹配到评价）。
  • 可查找：按客户名 / 订单号 / 会话号搜索，按状态筛选。
  • 好评内容可读：点开一条"已评价"会话，可看到邀请 → 点击 → 评价的时间线、这次客服会话的摘要（可跳转到 Support Agent 看完整对话）、评价全文与星级，以及一键前往 Trustpilot 查看原评价。
  • 聚焦正向口碑：明细只呈现 4–5 星好评；置信度、计费等内部信息不在此页展示（计费明细在账单页看）。

验收：每条会话状态清晰可懂；搜索 / 筛选生效；已评价会话能读到评价全文并跳转 Trustpilot。

3.3 配置与开关（设置）

用户故事：作为商家运营，我想自己把功能配好、开起来，并在配错时被拦住，以便不出现"开着却没效果"。

需求：集中在一张引导式"设置向导"里，三步既是上手指引也是配置入口——

配置项产品需求
① 连接 Trustpilot 主页商家填入自己的 Trustpilot 主页；保存时系统校验该页面是否真实可访问，配错会明确报错。仅在"已连接且近期正常"时显示为已验证（绿色），未配置 / 异常分别以灰 / 红提示。
② 每日邀请上限限制每天最多向多少顾客发邀请：提供预设档位 + "无限"选项，并清楚显示当前生效上限（"无限"就显示无限，不再出现 "Capped at 0/day" 这类费解文案）。
③ 开启 / 关闭总开关。未连接 Trustpilot 或校验未通过时不允许开启，从源头避免"开着却白发、0 归因"。
界面语言中文 / English 切换，界面文案即时全量切换；产品名与品牌词不翻译，顾客评价原文、客户名、订单号等保持原样。默认跟随商家在 MD 的账号语言。

验收：Trustpilot 未连接 / 校验失败时无法开启并有明确提示；每日上限设为无限时显示"无限"而非 0；配置保存有即时反馈。
